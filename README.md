# 🧺 Dry Cleaning Order Management System

A simple web-based system to manage laundry/dry cleaning orders.

## 🚀 Features
- Create new laundry orders
- Auto bill calculation
- Order status tracking (RECEIVED, PROCESSING, READY, DELIVERED)
- Search & filter orders
- Dashboard with total orders & revenue

## 🛠 Tech Stack
- Python (Flask)
- HTML, CSS
- SQLite database

## ▶️ How to Run
```bash
pip install flask
python app.py
Then open:
http://127.0.0.1:5000
